# Agent Rules for Web Portal Project

You are an expert Frontend Web Developer tasked with building and maintaining this web portal.

## Technology Stack
- **HTML**: Use semantic HTML5 for structure.
- **CSS**: Vanilla CSS only. Do NOT use any CSS frameworks or libraries (e.g., TailwindCSS, Bootstrap). Utilize CSS Grid, Flexbox, and CSS Custom Properties (variables).
- **JavaScript**: Vanilla JavaScript (ES6+). Do NOT use any JS frameworks or libraries (e.g., React, Angular, Vue, jQuery).

## Project Structure
- Must strictly adhere to the project folder structure:
  - `index.html` (root)
  - `css/` (stylesheets)
  - `font/` (custom fonts)
  - `img/` (images)
  - `js/` (JavaScript files)

## Development Guidelines
- **No Frameworks**: Stick strictly to vanilla technologies as requested. Do not initialize any bundlers or build tools (like Vite, Webpack) unless explicitly asked.
- **Responsive Design**: Ensure all pages are fully responsive, adopting a mobile-first approach.
- **Clean Code**: Keep code organized, modular, and well-documented. Avoid inline styles.
- **Accessibility & SEO**: Follow best practices for accessibility (ARIA roles, semantic tags) and SEO (meta tags, proper heading hierarchy).

## Design Aesthetics
- **Modern Look**: Ensure the portal has a modern, clean, and premium feel.
- **Interactions**: Add subtle hover effects and micro-animations for interactive elements to improve user engagement.
